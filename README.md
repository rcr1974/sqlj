# Paquete Markdown de SQLJ

Este paquete complementa la guía Word y la presentación PowerPoint con una edición modular en Markdown.

## Uso

Empieza por `00_INDICE_SQLJ.md` y continúa en orden.

Los diagramas utilizan Mermaid. GitHub, GitLab, Azure DevOps Wiki, Obsidian y otros visores pueden admitir Mermaid de forma nativa o mediante extensiones. Si el visor no lo admite, se mantiene una descripción alternativa.

## Alcance de los ejercicios

- Básico: sintaxis, variables host, `SELECT INTO`, inserciones e iteradores sencillos.
- Intermedio: joins, agrupaciones, modificaciones seguras y transacciones.
- Avanzado: operación completa de pedido, concurrencia optimista, reintentos e idempotencia.
